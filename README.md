\# Photo Animator (Web Prototype)



Веб-прототип приложения по “оживлению” фотографий: пользователь выделяет область маской, выбирает толщину кисти/ластика, запускает эффект и сохраняет результат в видео (WebM) или GIF.



Проект сделан как учебный и постепенно развивается до уровня “как в топовых приложениях”.



---



\## Возможности



- Загрузка фото и отображение на canvas
- Рисование маски кистью с **мягкими краями** (градиент)
- Ластик для точной правки маски
- Регулировка размера кисти
- Сброс маски одной кнопкой
- **Два типа анимации:**
  - **Дыхание** — лёгкое “пульсирующее” масштабирование выделенной области
  - **Поток** — плавный сдвиг текстуры под маской
- **Управление направлением потока**: влево / вправо
- Экспорт анимации:
  - **WebM** (30 fps)
  - **GIF** (20 fps)
- Выбор длительности экспорта: 3 / 5 / 10 секунд



---



\## Как запустить локально



\### 1) Склонировать репозиторий



```bash

git clone https://github.com/vikki198/photo-animator-web.git

cd photo-animator-web

```



\### 2) Запустить локальный сервер



Нужен установленный Python 3.x.



```bash

python -m http.server 8000

```



Открыть в браузере:



http://localhost:8000



> Важно: GIF-экспорт работает корректно только при запуске через локальный сервер (из-за Web Worker’ов).

\## Как пользоваться



1\. Нажми “Выбери фотографию” и загрузи изображение.

2\. С помощью кисти нарисуй маску на области, которую нужно оживить.

3\. При необходимости используй Ластик, чтобы аккуратно подправить маску.

4\. Настрой размер кисти слайдером.

5\. Выбери тип анимации:



   - Дыхание — выделенная зона “дышит”

   - Поток — область под маской плавно “течёт” в сторону




6\. Для эффекта “Поток” выбери направление:



   - Влево

   - Вправо



7\. Нажми “Запустить анимацию”, чтобы посмотреть результат.

8\. Если нужно, нажми “Сбросить выделение” и нарисуй новую маску.

9\. Для сохранения:



   - выбери длительность (3/5/10 сек)

   - нажми “Сохранить видео” или “Сохранить GIF”

\## Технологии



\- HTML / CSS / JavaScript

\- Canvas 2D API

\- requestAnimationFrame для анимации

\- MediaRecorder + canvas.captureStream() для WebM-экспорта

\- gif.js для сборки GIF в браузере
